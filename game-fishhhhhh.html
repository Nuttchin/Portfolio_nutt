SYSTEM & MECHANICS

Game Design & Mechanics (การออกแบบเกม)

ระบบเกมการเล่นสร้างขึ้นบนหลักการของ Information Asymmetry (ผู้เล่นมีข้อมูลมุมมองกว้างกว่าศัตรู แต่เปราะบางต่อการถูกตรวจพบ) โดยมีระบบหลักที่ขับเคลื่อนเกมเพลย์ 3 ส่วน:

AI Vision Cone & State Machine

กรวยสายตาของศัตรูแบ่งเป็น 3 สถานะ: สีเขียว (Unaware / ลาดตระเวนปกติ), สีเหลือง (Suspicious / ตรวจสอบเสียงผิดปกติ), และสีแดง (Alert / เข้าสู่สภาวะตามล่าและส่งสัญญาณเตือน)

Noise Propagation System

การก้าวเท้าของผู้เล่นสร้างวงคลื่นเสียงตามวัสดุพื้นผิว: พื้นพรมเสียงเงียบ (รัศมี 1m), พื้นกระเบื้องหิน (รัศมี 3.5m), และการวิ่งเร็ว (รัศมี 6m) ซึ่งศัตรูจะได้ยินและหันมาสำรวจ

Dynamic Shadow Concealment

คำนวณจุดมืดในฉาก (Shadow Volumes) หากผู้เล่นหมอบอยู่ในเงามืด ระยะการมองเห็นของศัตรูจะลดลง 70% เปิดโอกาสให้แอบแทรกซึมผ่านจุดตรวจได้

1

Infiltration Loop: Scout → Distract → Takedown / Bypass → Exfiltrate

ผู้เล่นศึกษาแพทเทิร์นการเดินของยาม, โยนสิ่งของสร้างเสียงล่อ (Distraction Object), เลือกที่จะลอบจัดการจากด้านหลังหรือหลบเลี่ยงผ่านทางช่องระบายอากาศ เพื่อไปยังห้องเป้าหมาย

2

Action Block Prototyping in Unity

ก่อนเริ่มงานอาร์ต ได้ทำการ Blockout ฉากด้วย Whitebox Geometry เพื่อทดสอบความกว้างของประตู มุมหักเลี้ยว และระยะเวลากระพริบของกล้องวงจรปิด เพื่อให้แน่ใจว่าเกมเพลย์มีความตึงเครียดที่สมบูรณ์แบบ
